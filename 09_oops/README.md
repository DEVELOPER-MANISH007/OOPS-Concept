# Python OOP Practice

This repository contains practical Python Object-Oriented Programming (OOP) concepts with examples and explanations.

## 📚 Topics Covered

### 08 - Operator Overloading

File: `08_oops.main.ipynb`

Concepts covered:
- Operator Overloading
- Dunder / Magic Methods
- `__add__()` → `+`
- `__eq__()` → `==`
- `__lt__()` → `<`
- `__gt__()` → `>`
- `__str__()` → `print(object)`

Includes examples using Student and Data Science Project classes.

---

### 09 - Multiple Inheritance & MRO

File: `09_multiple_inheritance_mro.ipynb`

Concepts covered:
- Multiple Inheritance
- Method Resolution Order (MRO)
- `mro()`
- `__mro__`
- Method conflicts
- Real-world ML pipeline example

The notebook demonstrates how Python resolves methods when a class inherits from multiple parent classes.
