# OOP - Operator Overloading

This module covers **Operator Overloading in Python OOP** using special (dunder) methods.

## 📌 Concepts Covered

- Operator Overloading
- Dunder / Magic Methods
- `__add__()` → `+`
- `__eq__()` → `==`
- `__lt__()` → `<`
- `__gt__()` → `>`
- `__str__()` → `print(object)`

## 💡 Examples

### Student Class

The `Student` class demonstrates:

- Adding marks of two objects using `+`
- Comparing marks using `==` and `<`
- Displaying object information using `__str__()`

### Data Science Project

The `DataScienceProject` class demonstrates comparing ML projects based on their accuracy using the `>` operator.

## 🧠 Key Learning

Operator overloading allows custom Python objects to behave naturally with built-in operators.

It makes classes more intuitive, readable, and Pythonic.
